# Site documentation

This repository builds **Local Nonsatiation** with Jekyll and Gulp and deploys it to GitHub Pages through GitHub Actions.

- [Setup and deployment](setup.md): dependencies, local builds, preview, and publishing.
- [Settings](settings.md): where configuration lives and which files are generated.
- [Writing posts](post.md): front matter, media, and including Markdown from another repository.
- [Features](features.md): the features supported by this site.
- [Legacy Netlify CMS files](netlify-cms.md): status of the inherited admin configuration.

The detailed operating manual is the [GitHub Pages and Jekyll Notes post](../_posts/2003-5-1-Github-Pages-And-Jekyll.md). These docs provide the short workflow and link to that manual for detailed options.
