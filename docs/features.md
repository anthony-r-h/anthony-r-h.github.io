# Features

This site started from Jekflix, but its current layouts and build differ from that template.

- Home card grid and list view, with tag-based inclusion/exclusion.
- Planning page grouped by `planning_tag`.
- Post and page layouts, tags, search, sitemap, and related-post links.
- Per-post typography and spacing overrides, optional table of contents, and MathJax.
- Mermaid diagrams, loaded when a page has a Mermaid code block.
- Local video, image galleries, CSV tables, and configurable charts.
- Build-time inclusion of public GitHub Markdown with relative image/link resolution.
- Optional multi-page posts through `jekyll-paginate-content`.
- Contact page with an obfuscated email link.
- GitHub Actions builds supporting custom Jekyll plugins, deployed to GitHub Pages.

See [Writing posts](post.md) and the [operating manual](../_posts/2003-5-1-Github-Pages-And-Jekyll.md) for usage. The previous template documentation's hero, Disqus, exit modal, Formspree contact form, and Netlify deployment instructions are not the current site workflow.
